# Package index

## Core Functions

- [`agrobox()`](agrobox.md) : Genera un grafico y analisis estadistico
  por grupo
- [`agroexcel()`](agroexcel.md) : Exporta tablas agrobox o agrosintesis
  a Excel
- [`agrosintesis()`](agrosintesis.md) : Sintetiza resultados
  estadísticos para múltiples variables
- [`agrotabla()`](agrotabla.md) : Exporta tablas de resultados a PNG via
  LaTeX (modo rapido)
